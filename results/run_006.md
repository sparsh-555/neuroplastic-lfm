## What Happened

### Injection point was the bottleneck

Runs 1–5 injected the cluster residual after all 16 layers, directly before `lm_head`. The base model spent 1.17B parameters calibrating exactly what distribution `lm_head` expects — any residual landing there out-of-distribution degrades PPL regardless of how well the cluster learned.

Run 006 injects at layer 8 via `register_forward_hook`. The corrected hidden state then propagates through 7 remaining layers (including 3 attention blocks at indices 10, 12, 14) before reaching `lm_head`. Those layers normalise the cluster's signal into the model's expected distribution.

Result: **14.5% science PPL improvement** (2.82 → 2.41), **12.2% creative PPL improvement** (4.36 → 3.83).

### Gate decreased, not increased

All previous runs showed the gate opening (0.047 → 0.058 to 0.25). Run 006 shows it **closing**: 0.047 → 0.032.

This is not a failure. At layer 8, the cluster's residual gets amplified by 7 downstream layers. A 3.2% injection at this depth has significantly more effective influence than a 25% injection at the final layer (Run 005 gate=0.25, PPL degraded). The optimizer found that the optimal gate at this injection depth is lower than the sigmoid(-3) initialisation — the correction doesn't need to be large to be useful when it is applied mid-model.

This is the key finding: **injection depth dominates gate magnitude**. Small gate, deep injection beats large gate, late injection.

### Cross-task PPL improvement

The science cluster (trained only on science data) improved creative PPL from 4.36 to 3.83. The creative cluster improved science PPL from 2.82 to 2.41. Both clusters generalise across tasks.

At layer 8, the cluster is correcting intermediate representations, not task-specific surface features. The learned residual at this depth appears to improve the quality of the model's internal processing generally — both tasks benefit because both tasks require good representations at the midpoint of the network.

This does not undermine the specialisation claim. Task-specific improvement is confirmed (science cluster trained on science improves science; creative cluster trained on creative improves creative). The cross-task improvement is a bonus that indicates the cluster has learned something genuinely useful at the representational level.

### TIES merge works for the first time

Previous merges produced results at or above baseline. Run 006's merge:
- Science: 2.82 → 2.42 (14.2% improvement)
- Creative: 4.36 → 3.83 (12.2% improvement)

Both tasks improve post-merge. The merged cluster is within 0.01 PPL of the best individual cluster on each task. TIES-Merging on CfC weight vectors successfully combines two trained clusters without catastrophic interference.

### τ_a dynamics minimal

`τ_a` moved from 0.0008 to 0.0008 (essentially flat). The CfC time constants are not changing significantly during training. This is consistent with a uniform `ts=1.0` — without varying timesteps, the `time_a`/`time_b` projections receive no temporal gradient signal. The functional neuroplasticity claim is structurally present in the architecture but not being exercised in this experiment.

## What Remains

1. **τ dynamics**: functional neuroplasticity claim requires variable `ts` to exercise `time_a`/`time_b`. With `ts=1.0` the τ mechanism is present but idle.
2. **Baseline forgetting comparison**: `baseline_finetuning.py` must be run to show that naive fine-tuning on creative data degrades science PPL — making the zero-forgetting result meaningful.
3. **LoRA baseline**: direct comparison against LoRA r=8 at same training scale and parameter budget.
4. **Autonomous spawn trigger**: currently clusters are spawned manually with pre-labelled datasets. A loss-threshold trigger with no manual `task_id` is needed for the full neuroplastic claim.
