## Gate Log (NeuroplasticLFM)

Gate started at sigmoid(-3) ≈ 0.047 and barely moved throughout training:

| Task | Gate step 0 | Gate step 500 | Loss step 0 | Loss step 500 |
|---|---|---|---|---|
| yelp | 0.0474 | 0.0459 | 18.75 | 0.35 |
| imdb | 0.0474 | 0.0454 | 19.25 | 0.05 |
| boolq | 0.0474 | 0.0447 | 3.41 | 0.17 |
| multirc | 0.0475 | 0.0486 | 7.44 | 0.18 |
| dbpedia | 0.0474 | 0.0497 | 11.13 | 0.26 |

**Root cause identified:** adapter_out randomly initialized (kaiming). At step 0 the cluster
adds random noise to the residual stream. Gradient correctly pushes gate toward closed to
suppress noise — deadlock with the cluster having no gradient pressure to learn useful
representations. Gate stuck in 0.045–0.050 range throughout.
