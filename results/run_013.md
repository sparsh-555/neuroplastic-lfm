## Purpose

Honest zero-forgetting peer comparison. O-LoRA adds a soft orthogonality regularisation
on LoRA A matrices to reduce inter-task interference and enable forward transfer. Same
benchmark, same config as Run 011.

Algorithm: `L = CE + λ₁ * Σ_{i<t} ||A_i @ A_t.T||_F²` (per layer, normalised by past task count)

## Analysis

### O-LoRA beats per-task LoRA (+0.8 AP pts, +0.015 FWT)

The orthogonal constraint is enabling genuine forward transfer — task 4 (multirc) benefits
from structure learned in earlier tasks (0.720 vs 0.670 per-task LoRA). This is O-LoRA's
theoretical advantage and it holds empirically here.

### NeuroplasticLFM vs O-LoRA: 1.6 AP point gap

O-LoRA AP = 0.846, NeuroplasticLFM AP = 0.830. This is above noise (pre-set threshold 1 pt).
O-LoRA is the stronger method on raw AP.

The tradeoff:
- **O-LoRA**: 442K params/task, task label needed at inference, orth loss computed during training, all past A matrices stored
- **NeuroplasticLFM**: 187K params/task (2.4× fewer), no task label at inference, no orth computation, no past matrix storage

### NeuroplasticLFM wins on boolq and dbpedia vs O-LoRA

NeuroplasticLFM boolq = 0.810 vs O-LoRA boolq = 0.790 (+2 pts).
NeuroplasticLFM dbpedia = 0.990 vs O-LoRA dbpedia = 0.940 (+5 pts).

The recurrent inductive bias (CfC) provides a structural advantage on tasks requiring
broader context integration, consistent with Run 012 CfC vs MLP finding.

O-LoRA wins on multirc (0.720 vs 0.640, +8 pts) — the forward transfer from earlier
QA-adjacent tasks (boolq → multirc) is the dominant factor there.

## Honest paper position

NeuroplasticLFM is not the best AP method on this benchmark — O-LoRA is. The honest
framing is a tradeoff:

**NeuroplasticLFM offers:**
- Architectural zero-forgetting (not learned via regularisation — no λ tuning needed)
- 2.4× fewer parameters per task (187K vs 442K)
- No task identity required at inference (O-LoRA and per-task LoRA need it)
- Structural advantage on context-heavy tasks (boolq, dbpedia)
- No past A matrix storage or orth loss computation overhead

**O-LoRA offers:**
- 1.6 pts higher AP overall
- Genuine forward transfer (FWT +0.185 vs +0.163)
- Especially strong on tasks with shared structure (multirc benefits from boolq subspace)

**Paper claim (revised):**
"NeuroplasticLFM matches O-LoRA's zero-forgetting guarantee at 2.4× lower parameter cost
and without task identity at inference, at a 1.6 AP point cost. It outperforms O-LoRA
on context-heavy tasks (boolq +2, dbpedia +5 pts), suggesting the recurrent inductive bias
is complementary to subspace orthogonality for tasks requiring sequence integration."

---

## Impact on NeurIPS assessment

O-LoRA being stronger on AP is expected — it has 2.4× more params and uses task labels.
The gap (1.6 pts) is real and must be acknowledged. However:
- NeuroplasticLFM's advantages are practical (deployment without task labels, smaller adapters)
- The per-task comparison is honest (NeuroplasticLFM wins on 2/5 tasks even vs O-LoRA)
- The LLaMA experiment remains the decisive test for whether the CfC advantage widens
