## Why this run is invalid

Post-hoc diagnostic (run after this experiment) revealed that the CfC gradient
path was completely severed by the zero-init adapter_out:

```
layer_0 time_a grad norm: 0.000000
layer_1 time_a grad norm: 0.000000
layer_2 time_a grad norm: 0.000000
```

The τ projections inside every CfCCell received **zero gradient** throughout all
five tasks.  The CfC ran with fixed random time constants — the liquid property
never activated.

**This experiment compared "non-functioning CfC" vs MLP**, not "liquid CfC vs MLP".
The result (MLP AP 0.818 > CfC AP 0.798) tells us nothing about whether ODE dynamics
outperform static MLPs, because ODE dynamics were not operating.

The "framing pivot" to "NCP-wired growing adapter" that was recorded based on this
run is **RETRACTED**.  CfC remains the primary substrate pending a valid ablation.

Fix applied in commit `f5e0c64`: `nn.init.normal_(adapter_out.weight, std=1e-3)`
replaces `nn.init.zeros_`.  This keeps initial output noise at ~0.001 (negligible)
while restoring the full gradient path to time_a / time_b.
