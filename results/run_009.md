## Gate Log (NeuroplasticLFM)

Gate started at sigmoid(0) = 0.500 and oscillated slightly around 0.5:

| Task | Gate step 0 | Gate step 500 | Loss step 0 | Loss step 500 |
|---|---|---|---|---|
| yelp | 0.5000 | ~0.497 | 17.25 | 0.0004 |
| imdb | 0.5000 | ~0.488 | 16.38 | 0.0001 |
| boolq | 0.5000 | ~0.496 | 2.44 | 0.0002 |
| multirc | 0.5000 | ~0.488 | 8.88 | 0.2002 |
| dbpedia | 0.5000 | ~0.503 | 12.63 | 0.0043 |

**Zero-init fix worked:** loss converges cleanly for 4/5 tasks. Gate starts at 0.5 and
oscillates minimally — once loss ≈ 0, gradient on gate is also ≈ 0 (no signal to open
further). Gate learning is a second-order effect at this training scale.

**MultiRC did not converge:** loss = 0.20 at step 500. This task (passage QA) needs
more capacity or more steps. Not fixed post-hoc — results stand as-is.

## Analysis

### What improved vs Run 008
- Yelp: 0.920 → 0.930 (gate fix helps simple classification)
- DBpedia: 0.940 → 0.960 (gate fix helps 14-class classification)
- Loss dynamics: all converging tasks now drop to ~0.0001 (vs ~0.35 with broken gate)

### What got worse vs Run 008
- IMDB: 0.780 → 0.820... wait, 0.820 is better (0.780 was Run 008 broken gate)
  Actually Run 008 IMDB = 0.780, Run 009 IMDB = 0.820 — improved
- BoolQ: 0.750 → 0.710 — slightly worse
- MultiRC: 0.650 → 0.570 — worse (convergence failure, not gate issue)

### AP dropped vs Run 008 (0.808 → 0.798)
Despite the gate fix improving individual task accuracy on yelp/imdb/dbpedia,
AP dropped because multirc regressed significantly (0.650 → 0.570). The cluster
still converges to near-zero loss on most tasks, but multirc is genuinely too hard
for 187K params in 500 steps. This is a capacity/steps constraint, not the gate.

### Honest paper position
- NeuroplasticLFM AP = 0.798 vs Sequential LoRA AP = 0.814 (16 points behind)
- NeuroplasticLFM AP = 0.798 vs Per-task LoRA AP = 0.842 (44 points behind)
- Zero-forgetting guarantee intact (BWT = 0.000, F.Ra = 0.000)
- 2.4× fewer params per task than per-task LoRA
- No task labels at inference (per-task LoRA requires them)
- NeuroplasticLFM wins on yelp (0.930) and dbpedia (0.960)

### Paper framing (tradeoff, not "best on all metrics")
NeuroplasticLM offers guaranteed zero forgetting with 2.4× fewer parameters and
no task-label requirement at inference, at a cost of ~4 AP points vs per-task LoRA
and ~1.6 AP points vs sequential LoRA. The AP gap is concentrated on harder QA
tasks (multirc, boolq) where 187K cluster capacity is insufficient.
